# Customer Support Ticket Triage System

## Project Overview
This project automates customer support ticket classification and routing using a Mock LLM-based system.

## Objectives
- Generate and process customer support datasets.
- Clean and preprocess the data.
- Perform customer segmentation.
- Classify support tickets into predefined categories.
- Manage token usage with a budget control system.
- Route tickets based on category and customer priority.

## Technologies Used
- Python
- Pandas
- NumPy
- Mock LLM
- Kaggle Notebook

## Project Workflow
1. Data Generation
2. Data Cleaning
3. Customer Segmentation
4. Ticket Classification
5. Token Budget Management
6. Final Ticket Routing
